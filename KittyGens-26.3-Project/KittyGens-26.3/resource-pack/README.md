KittyGens resource-pack starter
===============================
28 custom 16x16 pixel-art fur PNGs are in assets/kittygens/textures/item.

The included model JSONs are individual texture model templates. They are not yet connected to item overrides in a complete client-compatible pack; before distributing, wire these models to the exact custom model data/item-model system used by your 26.3 client and set the correct pack_format. The plugin currently creates tagged WHITE_DYE fur items, but does not yet assign per-tier client model components, so these textures are asset source material rather than in-game-visible textures by themselves.
